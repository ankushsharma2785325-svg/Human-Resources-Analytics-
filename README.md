# Human-Resources-Analytics-
README.md
Human Resources Analytics Dashboard
This project analyzes workforce data to provide insights into employee demographics, attrition trends, salary distribution, and employee satisfaction. The dashboard helps organizations make data-driven HR decisions.
Tools Used:
Power BI
Microsoft Excel
Key Features:

Employee Count Analysis
Gender Distribution
Attrition Monitoring
Department-wise Salary Analysis
Employee Satisfaction Tracking
Experience vs Salary Trends
